# codex-reset

A Chrome extension that alerts you when OpenAI Codex usage limits are reset, without keeping a website open.

Install **Reset Alerts for Codex** from the [Chrome Web Store](https://chromewebstore.google.com/detail/reset-alerts-for-codex/hkmlmgnpffiigiflpeggnonhdcmcpipi).

Reset data and alerts come from [Codex Resets](https://codex-resets.com).
